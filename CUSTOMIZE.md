# Customising this portfolio

See [Edit the website](README.md#edit-the-website) for the source of each part of the site, and [architecture](docs/architecture.md) for shared component and CSS rules.

Use `_data/navigation.yml` for navigation, `_data/resume.json` for the CV, and page front matter for `content_width: reading` or `content_width: wide`. Run `npm test` before publishing.
